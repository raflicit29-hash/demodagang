🎬 DEMO MODE
Semua fitur bisa dicoba dengan data contoh. Mode demo tidak menyediakan Backup, Restore, Export, atau penyimpanan permanen. Perubahan akan kembali ke data demo awal saat halaman dibuka ulang.
Catatan penting
Demo ini khusus untuk melihat dan mencoba fitur MR ALL. Untuk versi penuh, gunakan aplikasi pelanggan dengan penyimpanan dan backup yang aktif.
Catat barang
Barang biasa masuk sini. Setelah READY, cukup klik SOLD di baris barang — tidak perlu input ulang. HDD non-garansi tetap masuk sini. Kalau HDD memang dijual dengan garansi, gunakan menu Garansi HDD.
